# Personal-PD2-Stuff

Auto-update files for my PAYDAY 2 mods (SuperBLT updater).

| Mod | Download |
|---|---|
| Gilza DS Perk Buffs | `GilzaDSPerkBuffs.zip` |
| PD:TH Police Tactics | `PDTHPoliceTactics.zip` |

Install once by extracting a zip into `PAYDAY 2/mods/`. After that, updates show up in the BLT mod manager automatically.
